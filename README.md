# Feuerwehr-Quiz (NRW) – GitHub Pages

Single-File Web-App (HTML/JS/CSS) mit 30 Sekunden Timer pro Frage, direktem Feedback und Ergebnisliste.

## Schnellstart (GitHub Pages)
1. Neues **public** Repository erstellen (z. B. `feuerwehr-quiz`).
2. Dateien aus diesem Ordner hochladen (mindestens `index.html`).
3. In **Settings → Pages**:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
   - **Save**
4. Nach der Bereitstellung ist die Seite unter `https://<dein-name>.github.io/<repo-name>/` erreichbar.

## Lokal starten
Einfach `index.html` im Browser öffnen.
